# Quy tắc project

## Git workflow
- Không push trực tiếp vào main
- Luôn tạo branch feature (nhánh riêng để code chức năng)

## Code convention
- NodeJs (backend), ReactJs (frontend)

## Lưu ý khi sửa code
- Không sửa file core nếu chưa được sự chấp thuận từ người quản lý project
- Không sửa file của người khác nếu chưa được sự chấp thuận từ người đó
